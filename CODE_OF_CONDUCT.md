# Code of Conduct

This applies to every OpenPhase Labs repository, and to issues, pull requests,
and discussions in them.

## The standard

Be respectful, be specific, and assume good intent. Disagree with the work, not
with the person.

- **Be specific.** "This is wrong" helps nobody. "This field's range contradicts
  NTCIP 1202 §3.4" is a contribution.
- **Assume good intent.** A contributor who misread the spec made a mistake, not
  an attack. Correct the mistake.
- **Say when you are unsure.** Confident wrongness costs more review time than
  an honest question.

Hostile, harassing, or discriminatory behavior toward any contributor is not
tolerated. Neither is sustained disruption, deliberate intimidation, or personal
attacks. This holds regardless of how good the contribution is.

## Scope

This applies in project spaces and when representing the project in public.

## Enforcement

Report a problem to **admin@openphase-labs.com**. Reports are handled
confidentially and acknowledged within 72 hours.

Consequences depend on severity: a correction and a request to stop, a temporary
block from participation, or permanent removal from the project. Maintainers who
do not follow this code are subject to it in the same way as anyone else.
